# Q3 步骤二：跨风格迁移与缺陷化合物守护

潜因子空间维数 q = 77，风格 22 类。

缺陷化合物集合（1.csv 字段名）：
- DMS（二甲基硫，煮玉米/蔬菜味）: DMS
- 双乙酰（黄油/奶油味）: X2.3.butanedione
- 4VG（4-乙烯基愈创木酚，丁香/药味）: X4VG
- 反式-2-壬烯醛（纸板/陈旧味）: X.E..2.nonenal
- 酒花陈味标志物（蛇麻烯环氧化物等）: humulene.epoxide.II, X14.hydroxy.alpha.humulene, X.E..dihydro.apofarnesal

其中 6 个在生成模型的支持集内，1 个不在支持集内（X4VG）。
不在支持集内的缺陷物质在迁移过程中根本不会被改写，因此「不恶化」由构造保证；
在支持集内的用单调截断守护，超不过迁移前的值。

已用问题一的最终模型（E0 与 E1 两套森林平均）作为感官画像的读出器。

## 2 从 Pils/Lager 迁移到 Tripel

源风格真实样本 11 条。对每条样本反解潜变量 z = argmin ||Lambda z - (x - mu_src)||，
再用目标风格均值重建 x_new = mu_dst + Lambda z，个体在风格内的差异被完整保留。

缺陷守护：逐条样本比较迁移前后同一缺陷化合物的 log10 浓度，若升高则压回原值（只会降不会升）。

| 缺陷化合物 | 未守护时升高的样本数 | 守护后升高的样本数 | 处理方式 |
| --- | --- | --- | --- |
| DMS | 11 | 0 | 单调截断 |
| X.E..2.nonenal | 11 | 0 | 单调截断 |
| X.E..dihydro.apofarnesal | 3 | 0 | 单调截断 |
| X14.hydroxy.alpha.humulene | 0 | 0 | 单调截断 |
| X2.3.butanedione | 4 | 0 | 单调截断 |
| humulene.epoxide.II | 7 | 0 | 单调截断 |
| X4VG | 0 | 0 | 不在生成模型支持集内，迁移不改写 |

| 缺陷化合物 | 源风格均值（迁移前） | 迁移后均值 | 目标风格真实均值 | 是否劣于源 | 是否劣于目标 |

| DMS | 1.158 | 1.158 | 1.587 | 否 | 否 |
| X.E..2.nonenal | 0.004 | 0.004 | 0.412 | 否 | 否 |
