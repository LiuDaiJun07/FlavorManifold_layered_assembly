# 02 反标准化：0-6 分制标度还原（三口径并列）

## 1 口径与依据

4.csv 的 50 列均值中位数 0.019、标准差中位数 0.5536，说明每列被中心化过，
但标准化的分母不是本列样本标准差，故 (mu, sigma) 无法只用 4.csv 识别。

- 主口径 **sd**：sigma_j 取该维标准差，mu_j = -sigma_j * z_min_j，即最小观测值贴 0 分。
  该口径不再假设「1 个标准差 = 1 分」，而是承认标度与列内离散度成比例，
  是补丁 §3 指定的主口径（原 v1 用 sigma=1 并把论证写成「落在网格内」，该论证不成立，已修 D10）。
- 并列口径 **unit**：sigma=1，mu=-z_min，等价于 z 直接线性搬到 0-6。
- 并列口径 **minmax**：sigma=6/(z_max-z_min)，把训练集值域线性拉满 0-6。

三口径只影响连续分的绝对尺度，不影响 z 空间 R2；MAE 随口径同比例变化。
