# 施行性核查与必要调整

## 结论

原始1/2/4/6/8表、主线三个问题的输出和Python依赖齐备；8个逻辑CPU，可在独立compare目录执行大部分实验。不能原样把全部21项视为已具备有效实验前提。下列调整先记录，输出不回写主线。

| 项目 | 核查发现 | 处理 |
| --- | --- | --- |
| Windows目录 | q1/Q1等仅大小写不同，在默认NTFS中是同一目录 | 代码归入 methods/，结果归入 results/，数值数据归入 data/，断点归入 cache/；各目录按研究领域和实验编号细分，迁移时逐文件核验哈希 |
| 公共路径 | common.OUT默认指向不存在的旧main/Output | compare桥接中重设模块路径；原文件不改 |
| 样本对齐 | 4.csv条码被科学计数法舍入，只剩96种；beer仍250个唯一编号 | 按beer与风格验证250行严格一致，不用条码连接 |
| 固定折 | split_folds的小类别不足10时整体退回随机KFold | 直接复用06b的fold_id，另用真正StratifiedKFold作风格对照 |
| C2 | RepeatedKFold本身不分层 | 三次不同种子的StratifiedKFold，保留风格+高低键，披露稀有类别 |
| C1/B7 | 逐维ET全200树内层搜索开销高于文档估计 | 内层5折×4组用50树筛选，选中参数以200树全量重训并外层评估；完整保存超参，披露多保真预算 |
| C3 | dim4几何块实际31列，不是46；原c≠1时log/exp不互逆，距离缺1/sqrt(c) | 字段名拆块；同时跑原行为与compare内公式修正版，有限差分验证梯度 |
| C4 | ib_f仅为融合预测，未存5个成员 | 重新做内层五成员OOF；四成员消融复用外层成员预测，避免完全相同重训 |
| C4权重 | “逆R²”在负R²时失去权重意义 | 用逆残差方差即1/(1-R²)，明确记录 |
| C7 | 所列4×3×3是36组，不是12组 | 完整36组 |
| C8 | 3.xlsx有12张空白卡，不是10张真实评分；summary的12×50评分全0 | 只正式化z空间指标；不能算外部Kappa，缺真实外部标签 |
| C10 | 原Top3已用全250条标签选出，直接做OOF仍有选择泄漏 | 每折重做Spearman+Lasso+折内图扩散+200次bootstrap综合选择，内层独立填充/标准化；验证可重训选择算法，不冒充固定原名单外部验证 |
| C11 | 原API不返回BASE5预测器，完整PI成本高 | 按设计预算用200树小森林代理；报告不称其为BASE5重要性 |
| C12 | 04_final扩散实际用完整加权图，并未用01_graph的kNN图 | 同时给knn8基准与现行完整图的偏移 |
| C13 | 子采样频率的BCa需嵌套重抽样；对0/1蒙特卡洛重复做BCa不能替代原数据CI | 报频率Wilson蒙特卡洛区间，另做原数据bootstrap+jackknife的系数BCa；频率原数据BCa未冒充完成 |
| C14 | 混用阈值单位，浓度单位未逐列确证；无两套独立同基质来源 | 不造数据，提供来源表结构和前提不足报告 |
| C15/16 | 旧生成评估未严格隔离全部全局拟合；未建模列会造成真假分类器伪信号 | 所有生成拟合在训练折；评价仅限各训练折共同支持列；小风格额外LOO |
| C17 | 无250对源/目标配对谱，无法拟合所述样本级岭仿射 | T1改为源/目标边缘位置尺度仿射；不捏造配对 |
| C19 | 6.csv为本250样本的相关阵，不是独立外部数据 | 只检验读出器形式敏感性，不称外部验证 |
| C20 | 旧双曲“应力”是加权平方损失，MDS是stress-1；二者不能取比；原点切空间直线不等于一般测地线 | 重算同一stress-1；增加Mobius真测地线，保留现行路径 |

## 科学解释边界

10折共享训练集，50个目标也相关。配对检验、Friedman/Nemenyi的独立区组假设并不严格满足，统一作为探索性结果披露。非显著不等于等效/非劣；生成检验通过也不能证明分布相同。缺少外部标签或单位前提的项目必须标为前提不足。所有运行状态与科学验收状态分开。
